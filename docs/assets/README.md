# Repository social preview

`social-preview.png` is a 1280×640 PNG under 1 MB for GitHub repository settings.
`social-preview.svg` is its editable design source. Both are original project
artwork under the repository MIT license. Typography can vary with local fonts.

Upload the PNG under repository **Settings → General → Social preview → Edit**.
This setting requires an authenticated repository administrator; committing the
image alone does not activate it. No release/platform-support claim is included.
